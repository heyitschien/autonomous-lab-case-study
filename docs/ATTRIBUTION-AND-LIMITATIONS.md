# Attribution and Limitations

## Attribution

The project was AI-assisted and human-directed.

- **ChatGPT and other reasoning models:** research synthesis, alternatives,
  critique, systems reasoning, and documentation support
- **Cursor and coding agents:** scoped implementation, repository edits,
  testing support, and repetitive execution
- **GitHub:** issues, pull requests, provenance, review history, and durable
  project memory
- **Chien Escalera Duong:** framing, requirements, architecture and product
  decisions, model routing, acceptance criteria, privacy boundaries, review,
  and final accountability

The exact tool contribution varies by task. No model is treated as an
independent authority, and generated output is not considered validated merely
because it is persuasive.

## Limitations

- This is a public-safe process summary, not a complete system disclosure.
- It does not claim production trading, banking, lending, treasury, KYC/AML,
  regulatory, or enterprise financial implementation employment.
- It does not publish performance results, financial targets, private code,
  credentials, collaborator-sensitive information, or live operational data.
- The method is transferable as a way of organizing work; it does not create
  automatic subject-matter expertise in regulated or safety-critical domains.
- Deterministic checks and human review remain necessary for every real
  implementation.
